The hardware directory contains two sub-directories: `design` and `testing`.

# `hardware/design`

This directory contains the design files for the hardware developed. This includes 2D plans (technical drawings of every part of the final prototype) and building instructions. Everything that would allow someone else to reproduce the designs. 

# `hardware/testing`

If a testing rig was built to test the design, it can be documented here, as well as the testing protocols. No testing rig was built during this project.
